ระบบ POS ค้าของเก่า by.leolung — ระบบรับซื้อของเก่า (โปรแกรม Windows)
=====================================================

วิธีเปิดโปรแกรม (ตอนนี้)
-------------------------
ดับเบิลคลิกไฟล์ "เปิดโปรแกรม.bat" ในโฟลเดอร์นี้ โปรแกรมจะเปิดเป็นหน้าต่างแยก
ไม่ต้องเชื่อมอินเทอร์เน็ต ไม่ต้องเปิดเบราว์เซอร์

ข้อมูลเก็บไว้ที่ไหน
-------------------------
ไฟล์ข้อมูลสมาชิก แคตตาล็อกราคา และประวัติบิลทั้งหมด เก็บเป็นไฟล์จริงที่:
  %APPDATA%\scrap-shop-pos\scrap-pos-data.json
(พิมพ์ %APPDATA% ในช่อง Address bar ของ File Explorer เพื่อเปิดโฟลเดอร์นี้)

ไฟล์นี้เป็น JSON ธรรมดา สามารถคัดลอกสำรองข้อมูล (backup) ได้ตลอดเวลาโดยการ
คัดลอกไฟล์นี้ไปเก็บไว้ที่อื่น

เครื่องอ่านบัตรประชาชน (Smart Card Reader)
-------------------------
ถ้าเสียบเครื่องอ่านบัตรประชาชน (แบบ PC/SC ทั่วไป) เข้ากับคอมไว้ โปรแกรมจะเชื่อมต่อให้
อัตโนมัติตอนเปิดโปรแกรม (ไม่ต้องตั้งค่าอะไรเพิ่ม) เมื่อเสียบบัตรประชาชน:
  - ถ้าเลขบัตรตรงกับสมาชิกที่มีอยู่แล้ว → ระบบจะเลือกสมาชิกคนนั้นให้อัตโนมัติ พร้อมรูปถ่าย
  - ถ้ายังไม่เคยเป็นสมาชิก → ระบบจะเปิดฟอร์ม "เพิ่มสมาชิกใหม่" พร้อมกรอกชื่อ เลขบัตร
    และรูปถ่ายจากบัตรให้อัตโนมัติ เหลือแค่กรอกเบอร์โทรแล้วกดบันทึก

หมายเหตุ: ฟีเจอร์นี้ใช้โปรแกรมช่วย ThaiIdReader.exe (เขียนด้วย C#/.NET เรียก
winscard.dll ของ Windows โดยตรง) เพราะไลบรารีมาตรฐานฝั่ง Node.js (nfc-pcsc) ต้องคอมไพล์
native module ผ่าน Visual Studio C++ Build Tools ซึ่งอาจไม่มีติดตั้งไว้ในเครื่องร้าน — ตัว .exe
เป็นแบบ self-contained ไม่ต้องลง .NET เพิ่ม ถ้าเสียบบัตรแล้วไม่ขึ้นข้อมูล ลองถอดแล้วเสียบใหม่
หรือดูให้แน่ใจว่าไม่มีโปรแกรมอ่านบัตรอื่นเปิดค้างอยู่พร้อมกัน (การเปิดพร้อมกันหลายโปรแกรม
ทำให้แย่งกันคุยกับเครื่องอ่านจนอ่านไม่ออกได้)

หน้าต่างๆ ในโปรแกรม
-------------------------
แถบด้านบนมี 6 หน้า สลับได้ตลอดเวลา:
  - ขายสินค้า        : หน้าชั่งของ/คิดเงิน (หน้าเดิมที่ใช้ประจำ)
  - จัดการสินค้า      : เพิ่ม/แก้ไข/ลบ/เปลี่ยนชื่อสินค้าและราคา แยกออกมาเป็นหน้าเต็ม
  - ประวัติการขาย     : ดูบิลย้อนหลังทั้งหมด กดที่แถวเพื่อดูรายการ กดปุ่มรูปเครื่องพิมพ์
                       เพื่อพิมพ์ใบเสร็จบิลนั้นซ้ำได้ทันที (1 ใบเหมือนตอนขายจริง) หรือ
                       กดถังขยะเพื่อยกเลิกบิล
  - รายรับเสริม       : บันทึกรายได้เล็กน้อยนอกเหนือจากการซื้อของเก่า (เช่น ขายขวดน้ำ
                       ขายเศษของที่เหลือ) แยกยอดจากธุรกิจซื้อของเก่าหลัก ดูสรุปรายเดือนได้
  - เงินเดือน/เบิกเงิน : จัดการรายชื่อพนักงาน ตั้งเงินเดือนต่อคน บันทึกเงินเบิกรายวัน
                       ระบบคำนวณ "คงเหลือที่ต้องจ่าย" (เงินเดือน − เบิกไปแล้วในเดือนนั้น)
                       ให้อัตโนมัติทุกเดือน
  - ตั้งค่า           : ตั้งชื่อร้าน และตั้งค่าสำรองข้อมูลขึ้น Google Drive

รายรับเสริม และ เงินเดือน/เบิกเงิน
-------------------------
ทั้งสองหน้านี้มีกล่องสรุป "รายรับ-รายจ่าย" ของเดือนปัจจุบันอยู่ด้านบน แสดงยอดรวม
รายรับเสริม ลบด้วยยอดเงินเบิกพนักงานทั้งหมดในเดือนนั้น เป็นยอดสุทธิให้เห็นภาพรวม
ทันที (ยอดซื้อของเก่าหลักไม่ถูกนำมารวมในยอดสุทธินี้ เพราะเป็นธุรกิจหลักที่มีรายงาน
แยกอยู่แล้วในหน้า Excel/รายงานรายเดือน) ข้อมูลทั้งสองหน้านี้จะถูกบันทึกลง Excel
เพิ่มอีก 3 ชีต (รายรับเสริม, พนักงาน, เบิกเงิน) และซิงก์กับมือถือ/อุปกรณ์อื่นแบบ
เรียลไทม์เหมือนข้อมูลส่วนอื่นของโปรแกรมทุกประการ

แป้นตัวเลขในตัว (Numpad)
-------------------------
ตอนชั่งของ จะมีแป้นตัวเลขขนาดใหญ่โผล่ข้างช่องกรอกน้ำหนัก/ราคา กดแตะได้เลย
ไม่ต้องใช้คีย์บอร์ดจริงก็ได้ (เหมาะกับจอสัมผัส) และกด Enter บนคีย์บอร์ดจริง
ในช่องไหนก็ได้เพื่อเพิ่มรายการลงบิลทันที ใต้แป้นตัวเลขมีปุ่ม "เพิ่มรายการลงบิล"
(หรือ "บันทึกการแก้ไข" ถ้ากำลังแก้ไขอยู่) ให้กดยืนยันได้ทันทีโดยไม่ต้องเลื่อนจอ
ผ่านแป้นตัวเลข เหมาะมากตอนใช้งานบนมือถือ/แท็บเล็ตหน้าจอเล็ก

บันทึกภาพใบเสร็จอัตโนมัติ (สำรองข้อมูลแยกรายเดือน)
-------------------------
ทุกครั้งที่กด "บันทึกบิล" เสร็จ ระบบจะถ่ายภาพใบเสร็จเก็บเป็นไฟล์ PNG อัตโนมัติ
(เฉพาะที่เครื่องคอมหลักที่ติดตั้งโปรแกรม — มือถือ/แท็บเล็ตที่เชื่อมผ่านเบราว์เซอร์จะไม่
ถ่ายภาพ เพราะไม่มีสิทธิ์เข้าถึงไฟล์ในเครื่อง) ไฟล์ภาพจะถูกจัดเก็บแยกโฟลเดอร์ตามเดือน
ในโฟลเดอร์ "ใบเสร็จ" เช่น %APPDATA%\scrap-shop-pos\ใบเสร็จ\2026-09\ ชื่อไฟล์จะ
ขึ้นต้นด้วยเลขที่บิล เปิดดูย้อนหลังได้ตลอดเวลาโดยไม่ต้องเปิดโปรแกรม

ถ้าตั้งค่าเชื่อมต่อ Google Drive ไว้แล้ว (ดูหัวข้อถัดไป) ภาพใบเสร็จเหล่านี้จะถูก
สำรองขึ้น Google Drive ให้อัตโนมัติเช่นกัน โดยแยกโฟลเดอร์ย่อยตามเดือนเหมือนกับ
ที่เก็บในเครื่อง (โฟลเดอร์ "ใบเสร็จ" > โฟลเดอร์ปี-เดือน เช่น 2026-09 ภายในโฟลเดอร์
สำรองข้อมูลหลักบน Google Drive)

ส่งออกเป็น Excel
-------------------------
ไฟล์ Excel รวม (scrap-pos-data.xlsx) จะถูกสร้าง/อัปเดตอัตโนมัติทุกครั้งที่มีการ
เปลี่ยนแปลงข้อมูล (เพิ่มสินค้า แก้ราคา ขายของ บันทึกรายรับเสริม เบิกเงินพนักงาน ฯลฯ)
— ไม่ต้องกดส่งออกเอง เปิดไฟล์นี้ด้วย Excel ได้จากโฟลเดอร์ %APPDATA%\scrap-shop-pos\
ตลอดเวลา มี 7 ชีต: สินค้า, สมาชิก, รายการขาย, สรุปรายเดือน, รายรับเสริม, พนักงาน, เบิกเงิน

นอกจากนี้ยังมีปุ่ม "CSV วันนี้" / "CSV ทั้งหมด" ในโปรแกรม สำหรับส่งออกไฟล์ CSV
แยกต่างหากไปไว้ที่อื่นได้ตามต้องการ

รายงานยอดขายแยกรายเดือน (ละเอียด แยกวันที่)
-------------------------
นอกจากไฟล์ Excel รวมแล้ว ระบบจะสร้างไฟล์รายงานแยกเป็น "1 ไฟล์ต่อ 1 เดือน" ไว้ใน
โฟลเดอร์ย่อย "รายงานรายเดือน" ชื่อไฟล์เช่น ขาย-2026-09.xlsx แต่ละไฟล์จัดกลุ่ม
รายการตามวันที่ให้อัตโนมัติ พร้อมยอดรวมย่อยท้ายแต่ละวัน และยอดรวมทั้งเดือนที่
บรรทัดสุดท้าย — กดปุ่ม "เปิดโฟลเดอร์รายงานรายเดือน" ในหน้า "ตั้งค่า" เพื่อเข้าถึง
ไฟล์เหล่านี้ได้ทันที (ไฟล์ชุดนี้จะถูกสำรองขึ้น Google Drive ไปพร้อมกันด้วยถ้าตั้งค่า
การสำรองข้อมูลไว้แล้ว)

สำรองข้อมูลขึ้น Google Drive (อัตโนมัติ)
-------------------------
ไปที่หน้า "ตั้งค่า" จะมีการ์ด "สำรองข้อมูลขึ้น Google Drive" ต้องตั้งค่าครั้งแรก
ตามขั้นตอนนี้ (ทำครั้งเดียว ใช้เวลาประมาณ 5 นาที):

  1. เปิดเว็บ https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่ (หรือใช้โปรเจกต์เดิม)
  2. เมนู "APIs & Services > Library" ค้นหา "Google Drive API" แล้วกด Enable
  3. เมนู "APIs & Services > OAuth consent screen" เลือก External แล้วกรอกชื่อแอปพอผ่าน
  4. เมนู "APIs & Services > Credentials > Create Credentials > OAuth client ID"
  5. เลือกประเภท "Desktop app" ตั้งชื่ออะไรก็ได้ แล้วกด Create
  6. คัดลอก Client ID และ Client Secret มาใส่ในหน้า "ตั้งค่า" ของโปรแกรม แล้วกด "บันทึก"
  7. กดปุ่ม "เชื่อมต่อ Google Drive" — เบราว์เซอร์จะเปิดขึ้นให้ล็อกอิน Google แล้วอนุญาต
  8. เสร็จแล้ว โปรแกรมจะสำรองไฟล์ข้อมูล (Excel + JSON) ขึ้นโฟลเดอร์ชื่อ
     "ระบบ POS ค้าของเก่า by.leolung - สำรองข้อมูล" ใน Google Drive ของบัญชีนั้นให้อัตโนมัติทุก 15 นาที
     (และหลังบันทึกข้อมูลทุกครั้งจะรออัปโหลดภายใน 30 วินาที) หรือกด "สำรองข้อมูลตอนนี้"
     เพื่อสำรองทันทีก็ได้

เชื่อมมือถือกับคอมหลัก (ใช้ฐานข้อมูลเดียวกัน)
-------------------------
กดปุ่ม "เชื่อมต่ออุปกรณ์อื่น" มุมบนขวาของโปรแกรม จะขึ้นลิงก์ เช่น
http://192.168.1.xx:4173 — เปิดลิงก์นี้บนมือถือหรือแท็บเล็ตที่เชื่อม WiFi
วงเดียวกับคอมเครื่องนี้ (เบราว์เซอร์ทั่วไป Safari/Chrome ก็ได้ ไม่ต้องลงแอปเพิ่ม)
ข้อมูลสมาชิก แคตตาล็อกราคา และบิล จะซิงก์กับคอมหลักแบบเรียลไทม์ทันที
เพิ่มสมาชิกจากมือถือ ก็จะไปโผล่ที่คอมด้วย และกลับกัน

ข้อควรระวัง: ใช้ได้เฉพาะอุปกรณ์ที่อยู่ในวง WiFi เดียวกับร้านเท่านั้น
(ไม่ใช่อินเทอร์เน็ตสาธารณะ ไม่มีรหัสผ่านป้องกันเพิ่ม จึงควรใช้ WiFi ของร้านเอง
ที่ไม่แชร์รหัสให้คนนอก)

หมวดหมู่และรายการสินค้า
-------------------------
มีสินค้าตั้งต้นให้แล้วเกือบ 40 รายการ ครอบคลุมของที่ร้านรับซื้อของเก่าทั่วไปมักรับซื้อ
แบ่งเป็น 7 หมวดหมู่ (เศษเหล็ก, กระดาษ, พลาสติก, โลหะมีค่า, แก้ว, เครื่องใช้ไฟฟ้า/
อิเล็กทรอนิกส์, อื่นๆ) — ราคาที่ตั้งไว้เป็นตัวเลขเริ่มต้นโดยประมาณ ควรเข้าไปปรับที่
หน้า "จัดการสินค้า" ให้ตรงกับราคาตลาดจริงของร้านก่อนเปิดใช้งานจริง

สินค้าทุกชนิดมี "รหัสสินค้า" กำกับไว้ให้แล้ว (เช่น FE01 สำหรับเศษเหล็กหนา, PL01
สำหรับขวดใส PET) ตัวอักษรนำหน้าจะบอกหมวดหมู่คร่าวๆ (FE=เศษเหล็ก, PA=กระดาษ,
PL=พลาสติก, NF=โลหะมีค่า, GL=แก้ว, EL=เครื่องใช้ไฟฟ้า, MS=อื่นๆ) ช่วยให้จำง่ายขึ้น
แก้ไขรหัสให้เป็นแบบที่ร้านคุ้นเคยเองได้ที่หน้า "จัดการสินค้า" (ช่องแรกสุดของแต่ละแถว)
รหัสจะแสดงบนปุ่มเลือกสินค้าหน้าขายสินค้าด้วย และมีคอลัมน์ในไฟล์ Excel ชีต "สินค้า"

เพิ่มหมวดหมู่ใหม่ได้เองที่หน้า "จัดการสินค้า" ด้านบนสุด (เช่น เศษไม้, เศษยาง ฯลฯ)
พิมพ์ชื่อแล้วกด "เพิ่มหมวดหมู่" หมวดหมู่ที่ยังมีสินค้าอยู่จะลบไม่ได้ (ต้องย้าย/ลบสินค้า
ในหมวดนั้นออกก่อน กันข้อมูลสินค้าตกหล่น)

หมายเหตุสำคัญ: ถ้าอัปเดตโปรแกรมเป็นเวอร์ชันใหม่ในอนาคต ระบบจะ "เติม" เฉพาะ
หมวดหมู่/สินค้าใหม่ที่ยังไม่เคยมีเท่านั้น ชื่อ ราคา และหมวดหมู่ที่แก้ไขเองไว้จะไม่ถูก
เขียนทับหรือหายไปเด็ดขาด

การอัปเกรดเป็นตัวติดตั้ง (.exe พร้อมไอคอนหน้าจอ/เมนู Start)
-------------------------------------------------------------
ตอนนี้สร้างเป็นตัวติดตั้งแบบเต็มรูปแบบไม่ได้ เพราะเครื่องมือสร้างตัวติดตั้ง
(electron-builder) ต้องการสิทธิ์สร้าง symbolic link ซึ่ง Windows ปิดไว้โดย
ค่าเริ่มต้นสำหรับผู้ใช้ทั่วไป วิธีแก้ (เลือกอย่างใดอย่างหนึ่ง):

  1) เปิด Developer Mode:
     Settings > Privacy & Security > For developers > Developer Mode > เปิด
     (ปลอดภัย เป็นการตั้งค่ามาตรฐานของ Windows ไม่กระทบความปลอดภัยเครื่อง)

  2) หรือรันคำสั่ง build จาก Terminal ที่เปิดแบบ "Run as Administrator"

หลังจากทำอย่างใดอย่างหนึ่งแล้ว แจ้งกลับมาเพื่อให้สร้างไฟล์ติดตั้ง (.exe) ต่อได้เลย

โครงสร้างโปรเจกต์
-------------------------
main.js         - โปรเซสหลักของ Electron (จัดการไฟล์ข้อมูล, กล่องบันทึกไฟล์)
preload.js      - สะพานเชื่อมข้อมูลอย่างปลอดภัยระหว่างโปรแกรมกับหน้าจอ
renderer/       - หน้าตาโปรแกรม (React) และไฟล์ฟอนต์/ไลบรารีที่ฝังไว้ในเครื่อง
card-reader/    - โมดูลอ่านบัตรประชาชนผ่านเครื่องอ่านสมาร์ทการ์ด (nfc-pcsc)
